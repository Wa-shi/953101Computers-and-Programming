ข้อที่ 1: Ex 1: การ Trace การทำงานของ While Loop พื้นฐาน

Loop Flow & Counter Lab06A_WhileLoop/Task1_Trace.java
🎯 จุดประสงค์และเป้าหมายของโปรแกรม
ทำความเข้าใจวงจรการทำงาน (Execution Cycle) ของคำสั่ง while, การตรวจสอบเงื่อนไขก่อนเข้าลูป, และการเปลี่ยนแปลงค่าตัวแปรนับรอบ (Counter)
ซอร์สโค้ดฉบับสมบูรณ์ (Task1_Trace.java):
// SE101 - Lab 6A: Task 1 (Exercise 1) // Trace the while Loop public class Task1_Trace { public static void main(String[] args) { int count = 0; while (count < 4) { System.out.println("count = " + count); count++; } System.out.println("Done"); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. ประกาศตัวแปรนับรอบ int count = 0; เป็นค่าเริ่มต้น
  2. เข้าสู่เงื่อนไข while (count < 4): โปรแกรมจะตรวจสอบว่า count น้อยกว่า 4 หรือไม่ หากเป็นจริง (true) จึงจะเข้าไปทำงานในปีกกา
  3. ภายในลูป: พิมพ์ข้อความ "Count is " + count ออกทางหน้าจอ
  4. เพิ่มค่า count++ ทีละ 1 (หากลืมบรรทัดนี้จะกลายเป็น Infinite Loop ทันที)
  5. เมื่อ count กลายเป็น 4 การตรวจสอบเงื่อนไข 4 < 4 จะเป็นเท็จ (false) ทำให้โปรแกรมหลุดออกจากลูป
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
ตารางจำลองการทำงาน (Trace Table): รอบที่ | ค่า count ก่อนตรวจ | เงื่อนไข (count < 4) | ผลการพิมพ์ทางจอภาพ | ค่า count หลังเพิ่ม (count++) ------------------------------------------------------------------------------------------ 1 | 0 | 0 < 4 (True) | Count is 0 | 1 2 | 1 | 1 < 4 (True) | Count is 1 | 2 3 | 2 | 2 < 4 (True) | Count is 2 | 3 4 | 3 | 3 < 4 (True) | Count is 3 | 4 - | 4 | 4 < 4 (False) | (หลุดออกจากลูป) | 4 ผลลัพธ์หลังจบลูป: ตัวแปร count มีค่าสุดท้ายเท่ากับ 4 (วนทำงานจริง 4 รอบ)
🔄 แบบต่างๆ และรูปแบบที่อาจเจอในข้อสอบ (Variations & Exam Tweaks)
  • เปลี่ยนเงื่อนไขเป็น <= : ถ้าแก้เป็น while (count <= 4) ลูปจะวน 5 รอบ (count = 0, 1, 2, 3, 4) และค่าสุดท้ายของ count จะเป็น 5
  • เริ่มนับจาก 1: int count = 1; while (count <= 4) จะได้รอบที่ count เป็น 1, 2, 3, 4 เช่นกัน แต่วิธีนี้เหมาะกับการนับจำนวนชิ้นงาน
  • เขียนแบบ Prefix Increment ในเงื่อนไข: while (++count < 4) ค่า count จะถูกบวก 1 ก่อน นำไปตรวจสอบเงื่อนไข
⚠️ จุดที่ต้องระวัง & กับดักข้อสอบ (Common Mistakes & Traps)
ข้อสอบ Trace ข้อเขียนมักถามว่า 'หลังจบลูป ตัวแปร count จะมีค่าเท่าใด?' นักศึกษามักตอบ 3 (เพราะเห็นตัวเลขสุดท้ายที่พิมพ์คือ 3) แต่คำตอบที่ถูกต้องคือ 4 เพราะต้องเพิ่มเป็น 4 ก่อนจึงจะทำให้เงื่อนไขเป็นเท็จและหลุดลูปได้

ข้อที่ 2: Ex 2: การนับถอยหลังและการตรวจสอบเลขคู่-คี่ (Countdown & Modulo)

Decrement Loop & If-Else Branching Lab06A_WhileLoop/CountDown.java
🎯 จุดประสงค์และเป้าหมายของโปรแกรม
ฝึกการสร้างลูปนับถอยหลัง (Decrement) และการนำตัวดำเนินการโมดูโล (%) มาใช้แยกแยะเลขคู่ (Even) และเลขคี่ (Odd)
ซอร์สโค้ดฉบับสมบูรณ์ (CountDown.java):
public class CountDown { public static void main(String[] args) { int i = 10; while (i >= 2) { System.out.println(i + (i % 2 == 0 ? " Even" : " Odd")); i--; } } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. กำหนดค่าเริ่มต้น int i = 10; (เริ่มจากค่ามาก)
  2. เงื่อนไข while (i >= 2): วนทำงานตราบใดที่ i ยังมีค่ามากกว่าหรือเท่ากับ 2
  3. ตรวจสอบเลขคู่/คี่: ใช้ if (i % 2 == 0) ถ้าเศษเป็น 0 แปลว่าเป็นเลขคู่ ให้พิมพ์คำว่า 'Even' ถ้าไม่ใช่พิมพ์ 'Odd'
  4. ลดค่าตัวแปร: i-- เพื่อให้ค่านับถอยหลังลงไปเรื่อยๆ เข้าใกล้จุดสิ้นสุด
  5. เมื่อ i ลดลงเหลือ 1 เงื่อนไข 1 >= 2 จะเป็นเท็จ ทำให้หยุดการทำงาน
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
ลำดับการประมวลผล: i = 10 -> 10 % 2 == 0 (True) -> พิมพ์: 10 Even -> i ลดเหลือ 9 i = 9 -> 9 % 2 == 0 (False) -> พิมพ์: 9 Odd -> i ลดเหลือ 8 i = 8 -> 8 % 2 == 0 (True) -> พิมพ์: 8 Even -> i ลดเหลือ 7 ... i = 2 -> 2 % 2 == 0 (True) -> พิมพ์: 2 Even -> i ลดเหลือ 1 i = 1 -> 1 >= 2 (False) -> จบลูปทันที
🔄 แบบต่างๆ และรูปแบบที่อาจเจอในข้อสอบ (Variations & Exam Tweaks)
  • เขียนแบบย่อด้วย Ternary: System.out.println(i + (i % 2 == 0 ? " Even" : " Odd"));
  • ลดทีละ 2 เพื่อพิมพ์เฉพาะเลขคู่: for (int i = 10; i >= 2; i -= 2) ไม่ต้องใช้ if เช็ค
  • นับถอยหลังถึง 0: เปลี่ยนเงื่อนไขเป็น while (i >= 0) ตัวเลข 0 จะถือว่าเป็น Even
⚠️ จุดที่ต้องระวัง & กับดักข้อสอบ (Common Mistakes & Traps)
ระวังการเขียนเครื่องหมายเปรียบเทียบกลับด้าน เช่น เผลอเขียน i <= 2 ทำให้เงื่อนไขเป็นเท็จตั้งแต่รอบแรก (10 <= 2 คือ false) ส่งผลให้ลูปไม่ทำงานเลยแม้แต่รอบเดียว

Sentinel-Controlled Loop & Statistics Lab06A_WhileLoop/SumUntilZero.java
🎯 จุดประสงค์และเป้าหมายของโปรแกรม
เรียนรู้รูปแบบ Sentinel-Controlled Loop ซึ่งเป็น Pattern สำคัญอันดับหนึ่งของข้อสอบแล็บ โดยรับข้อมูลจากผู้ใช้ไปเรื่อยๆ จนกว่าจะเจอเลขระบุการหยุด (Sentinel Value)
ซอร์สโค้ดฉบับสมบูรณ์ (SumUntilZero.java):
// SE101 - Lab 6A: Exercise 3 (SumUntilZero.java) import java.util.Scanner; public class SumUntilZero { public static void main(String[] args) { Scanner scanner = new Scanner(System.in); int sum = 0; int count = 0; int num; while (true) { System.out.print("Enter a number (0 to stop): "); num = scanner.nextInt(); if (num == 0) { break; } sum += num; count++; } System.out.println("You entered " + count + " numbers."); System.out.println("Sum = " + sum); scanner.close(); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. สร้าง Scanner และตัวแปรสะสมผลรวม sum = 0, ตัวแปรนับจำนวน count = 0
  2. ใช้ลูป while (true) เพื่อรับค่าวนซ้ำอย่างไม่จำกัดรอบ
  3. รับค่าจากผู้ใช้: int num = sc.nextInt();
  4. ตรวจสอบ Sentinel ทันที: if (num == 0) break; ออกจากลูปทันทีถ้าผู้ใช้ป้อน 0
  5. หากไม่ใช่ 0 ให้นำไปสะสม sum += num; และนับเพิ่ม count++;

🎯 จุดประสงค์และเป้าหมายของโปรแกรม
ฝึกใช้ตัวดำเนินการตรรกะระดับบิต Exclusive OR (^) กับการตัดขึ้นบรรทัดใหม่ทุกๆ 10 จำนวน
ซอร์สโค้ดฉบับสมบูรณ์ (Divisibility.java):
// SE101 - Lab 6A: Exercise 5 (Divisibility.java) import java.util.Scanner; public class Divisibility { public static void main(String[] args) { Scanner scanner = new Scanner(System.in); System.out.print("Enter n: "); int n = scanner.nextInt(); int count = 0; int num = 1; while (num <= n) { if ((num % 5 == 0) ^ (num % 7 == 0)) { System.out.print(num + " "); count++; if (count % 10 == 0) { System.out.println(); } } num++; } if (count % 10 != 0) { System.out.println(); } System.out.println("End."); scanner.close(); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. วนลูปตรวจสอบตัวเลขตั้งแต่ 100 ถึง 200 ด้วย int num = 100; while (num <= 200)
  2. สร้างเงื่อนไขตรวจสอบ: (num % 5 == 0) ^ (num % 7 == 0)
    เครื่องหมาย ^ (XOR) จะเป็นจริงก็ต่อเมื่อเงื่อนไขฝั่งใดฝั่งหนึ่งเป็นจริงเพียงฝั่งเดียวเท่านั้น
  3. หากเข้าเงื่อนไข: พิมพ์ตัวเลขตามด้วยช่องว่าง System.out.print(num + " "); และเพิ่มตัวนับ count++;
  4. ขึ้นบรรทัดใหม่ทุก 10 ตัว: ตรวจสอบ if (count % 10 == 0) System.out.println();
  5. เพิ่มค่า num++; ไปตรวจตัวเลขถัดไป
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
การทดสอบค่าความจริงของเงื่อนไข XOR: - ตัวเลข 100: 100 % 5 == 0 (True), 100 % 7 == 0 (False) -> True ^ False = True -> พิมพ์! - ตัวเลข 105: 105 % 5 == 0 (True), 105 % 7 == 0 (True) -> True ^ True = False -> ไม่พิมพ์! (เพราะหารลงทั้งคู่) - ตัวเลข 101: 101 % 5 == 0 (False), 101 % 7 == 0 (False)-> False ^ False = False-> ไม่พิมพ์! - ตัวเลข 140: หารลงทั้ง 5 และ 7 (35 * 4) -> True ^ True = False -> ไม่พิมพ์!
🔄 แบบต่างๆ และรูปแบบที่อาจเจอในข้อสอบ (Variations & Exam Tweaks)
  • เขียนโดยไม่ใช้ ^ : (num % 5 == 0 || num % 7 == 0) && !(num % 5 == 0 && num % 7 == 0)
  • หารลงตัวทั้งคู่ (AND): num % 5 == 0 && num % 7 == 0 หรือ num % 35 == 0
  • เปลี่ยนจำนวนต่อบรรทัด: เปลี่ยนเป็น 5 ตัวต่อบรรทัดด้วย count % 5 == 0
⚠️ จุดที่ต้องระวัง & กับดักข้อสอบ (Common Mistakes & Traps)
เข้าใจผิดว่าเครื่องหมาย ^ คือการยกกำลัง (เช่น 2^3) ในภาษา Java เครื่องหมาย ^ คือ Bitwise Exclusive OR เท่านั้น หากต้องการยกกำลังต้องเรียก Math.pow(base, exp)

public class Exercise1 { public static void main(String[] args) { // Step 1: เริ่มต้น loop โดยให้ i = 1 // Step 2: ตรวจสอบเงื่อนไข i <= 4 ถ้าเป็นจริงจะเข้าทำงานใน loop // Step 3: ทำงานจบ 1 รอบ จะสั่ง i++ (เพิ่มค่า i ทีละ 1) for (int i = 1; i <= 4; i++) { System.out.println(i + " squared = " + (i * i)); } System.out.println("Done"); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. หัวลูป for (int i = 1; i <= 4; i++) ประกอบด้วย:

    2. i <= 4; วนซ้ำตราบเท่าที่ i ไม่เกิน 4
    3. i++ เพิ่มค่า i ทีละ 1 หลังจบรอบ
  2. ภายในลูป: คำนวณค่ากำลังสอง i * i แล้วแสดงผลด้วย System.out.println(i + " squared = " + (i * i));

  4. หลังจบลูป: พิมพ์คำว่า 'Done!'

public class BreakContinue { public static void main(String[] args) { System.out.print("Snippet A: "); for (int i = 1; i <= 10; i++) { if (i == 6) break; System.out.print(i + " "); } System.out.println(); System.out.print("Snippet B: "); for (int i = 1; i <= 10; i++) { if (i % 3 == 0) continue; System.out.print(i + " "); } System.out.println(); } }

    - ตรวจสอบ if (i % 3 == 0) continue;

ข้อที่ 12: Ex 5: การหาตัวหารร่วมมาก (Greatest Common Divisor - GCD)

Brute Force Search Algorithm Lab07A_ForLoop/GCD.java
🎯 จุดประสงค์และเป้าหมายของโปรแกรม
สร้างอัลกอริทึมค้นหาตัวหารร่วมมากของจำนวนเต็มบวก 2 จำนวน ด้วยวิธี Brute-force Search จากล่างขึ้นบน
ซอร์สโค้ดฉบับสมบูรณ์ (GCD.java):
import java.util.Scanner; public class GCD { public static void main(String[] args) { Scanner input = new Scanner(System.in); System.out.print("Enter n1: "); int n1 = input.nextInt(); System.out.print("Enter n2: "); int n2 = input.nextInt(); int gcd = 1; for (int k = 2; k <= n1 && k <= n2; k++) { if (n1 % k == 0 && n2 % k == 0) { gcd = k; } } System.out.println("GCD(" + n1 + ", " + n2 + ") = " + gcd); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. รับจำนวนเต็มบวก 2 ตัว n1 และ n2 จากผู้ใช้
  2. กำหนดค่าเริ่มต้นของ ห.ร.ม. int gcd = 1; (เพราะจำนวนเต็มบวกใดๆ ย่อมมี 1 เป็นตัวหารร่วมเสมอ)
  3. หาขอบเขตสูงสุดที่จะทดสอบ: ตัวหารร่วมไม่มีทางเกินค่าน้อยของสองตัว จึงเริ่มลูป int k = 2; k <= n1 && k <= n2; k++
  4. ตรวจสอบเงื่อนไขการหารลงตัวทั้งคู่: if (n1 % k == 0 && n2 % k == 0)
  5. หาก k หารทั้งสองจำนวนลงตัว ให้อัปเดต gcd = k; (ค่า k ที่มากขึ้นเรื่อยๆ จะทับค่าเดิมจนได้ค่าที่มากที่สุด)
  6. เมื่อจบลูป แสดงผลค่า gcd ที่ได้
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
ตัวอย่างการหา GCD ของ n1 = 24 และ n2 = 36: เริ่มต้น: gcd = 1, ทดสอบ k = 2 ถึง 24 - k = 2: 24%2==0 และ 36%2==0 -> จริง -> gcd = 2 - k = 3: 24%3==0 และ 36%3==0 -> จริง -> gcd = 3 - k = 4: 24%4==0 และ 36%4==0 -> จริง -> gcd = 4 - k = 6: 24%6==0 และ 36%6==0 -> จริง -> gcd = 6 - k = 12: 24%12==0 และ 36%12==0 -> จริง -> gcd = 12 ... ไม่พบตัวหารร่วมที่มากกว่านี้ ผลลัพธ์: GCD of 24 and 36 is 12
🔄 แบบต่างๆ และรูปแบบที่อาจเจอในข้อสอบ (Variations & Exam Tweaks)
  • ค้นหาถอยหลังจากบนลงล่าง (Fast Brute-force): เริ่มจาก Math.min(n1, n2) ลงมาหา 1 ตัวแรกที่หารลงทั้งคู่คือ ห.ร.ม. ทันที แล้วสั่ง break ได้เลย
  • Euclidean Algorithm (วิธีของยุคลิดด้วย Modulo): มีประสิทธิภาพสูงสุด $O(\log N)$
    while (n2 != 0) { int temp = n2; n2 = n1 % n2; n1 = temp; } return n1;
  • หา ค.ร.น. (LCM): ใช้สูตร $LCM(a, b) = (a \times b) / GCD(a, b)$
⚠️ จุดที่ต้องระวัง & กับดักข้อสอบ (Common Mistakes & Traps)
ตั้งค่าเริ่มต้น gcd = 0 หากป้อนตัวเลขที่เป็น Coprime กัน (เช่น 7 และ 9) ลูปจะไม่เจอตัวหารตั้งแต่ 2 ขึ้นไป ส่งผลให้โปรแกรมตอบว่า gcd เป็น 0 ซึ่งผิดหลักคณิตศาสตร์ ค่าเริ่มต้นต้องเป็น 1 เสมอ

ข้อที่ 13: Ex 6: การพิมพ์จำนวนเฉพาะ 50 ตัวแรก (Prime Numbers & Primality Test)

Nested Loop & Primality Testing Lab07A_ForLoop/PrimeNumbers.java
🎯 จุดประสงค์และเป้าหมายของโปรแกรม
สร้าง Nested Loops เพื่อค้นหาและแสดงจำนวนเฉพาะ (Prime Numbers) 50 ตัวแรก โดยจัดแถวละ 10 จำนวนอย่างเป็นระเบียบ
ซอร์สโค้ดฉบับสมบูรณ์ (PrimeNumbers.java):
public class PrimeNumbers { public static void main(String[] args) { int count = 0; int number = 2; while (count < 50) { boolean isPrime = true; for (int divisor = 2; divisor <= number / 2; divisor++) { if (number % divisor == 0) { isPrime = false; break; } } if (isPrime) { System.out.print(number + " "); count++; if (count % 10 == 0) { System.out.println(); } } number++; } } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. กำหนดตัวแปร: int count = 0; (นับจำนวนเฉพาะที่พบ), int number = 2; (ตัวเลขแรกที่จะทดสอบ)
  2. ลูปนอก while (count < 50): ทำงานตราบใดที่ยังพบจำนวนเฉพาะไม่ครบ 50 ตัว
  3. สมมติให้ตัวเลขนั้นเป็นจำนวนเฉพาะไว้ก่อน: boolean isPrime = true;
  4. ลูปใน: วนทดสอบตัวหาร for (int divisor = 2; divisor <= number / 2; divisor++)
  5. หาก number % divisor == 0: แปลว่ามีตัวหารลงตัว แสดงว่าไม่ใช่จำนวนเฉพาะ ให้ตั้ง isPrime = false; break;
  6. ตรวจสอบหลังลูปใน: ถ้า isPrime == true ให้นับเพิ่ม count++; แล้วพิมพ์
  7. ตัดบรรทัดใหม่ทุก 10 ตัว: if (count % 10 == 0) System.out.println();
  8. เพิ่ม number++; เพื่อทดสอบตัวเลขถัดไป
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)

Nested Loops & Geometric Pattern Printing Lab07A_ForLoop/Pyramid.java
🎯 จุดประสงค์และเป้าหมายของโปรแกรม
สร้างลูปซ้อน 3 ชั้น (Nested Loops) เพื่อจัดตำแหน่งช่องว่างและพิมพ์ตัวเลขยกกำลังของ 2 ($2^0, 2^1, ..., 2^k$) ในรูปทรงพีระมิดหน้าจั่วกึ่งกลางหน้าจออย่างสมบูรณ์แบบ
ซอร์สโค้ดฉบับสมบูรณ์ (Pyramid.java):
public class Pyramid { public static void main(String[] args) { int totalRows = 7; for (int row = 1; row <= totalRows; row++) { for (int space = 1; space <= totalRows - row; space++) { System.out.print(" "); } for (int col = 0; col < row; col++) { int value = (int) Math.pow(2, col); System.out.printf("%4d", value); } System.out.println(); } } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. กำหนดความสูงของพีระมิด int totalRows = 7; (หรือ 8)
  2. ลูปชั้นนอก (Outer Loop): for (int row = 1; row <= totalRows; row++) ควบคุมแถวตั้งแต่ 1 ถึง 7
  3. ลูปชั้นในที่ 1 (Leading Spaces): for (int space = 1; space <= (totalRows - row) * 2; space++) System.out.print(" "); พิมพ์ช่องว่างเยื้องซ้ายเพื่อดันตัวเลขให้เป็นทรงสามเหลี่ยมพีระมิดกึ่งกลาง
  4. ลูปชั้นในที่ 2 (Numbers): for (int col = 0; col < row; col++)
    - คำนวณเลขยกกำลังฐานสอง: (int)Math.pow(2, col)
    - จัดรูปแบบตัวเลขให้กว้าง 4 ช่องพอดีเสมอด้วย System.out.printf("%4d", value);
  5. ขึ้นบรรทัดใหม่เมื่อพิมพ์จบแถว: System.out.println();
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
โครงสร้างการคำนวณแต่ละแถว: Row 1: (7-1)*2 = 12 spaces | pow(2,0) = 1 Row 2: (7-2)*2 = 10 spaces | pow(2,0)=1, pow(2,1)=2 Row 3: (7-3)*2 = 8 spaces | pow(2,0)=1, pow(2,1)=2, pow(2,2)=4 ... Row 7: (7-7)*2 = 0 spaces | 1 2 4 8 16 32 64 รูปทรง Output ที่ถูกต้องตามโจทย์ (Centered Pyramid): 1 1 2 1 2 4 1 2 4 8 1 2 4 8 16 1 2 4 8 16 32 1 2 4 8 16 32 64
🔄 แบบต่างๆ และรูปแบบที่อาจเจอในข้อสอบ (Variations & Exam Tweaks)
  • พีระมิดสมมาตรแบบเพิ่มแล้วลด (Palindrome Pyramid): พิมพ์ 1 2 4 8 4 2 1 ในแถวเดียว โดยใช้ลูปเลขขาขึ้นแล้วตามด้วยลูปเลขขาลง
  • พีระมิดดาว (*): แทนที่ตัวเลขด้วยเครื่องหมายดอกจัน *
  • สามเหลี่ยมชิดซ้าย (Left-aligned): ตัดลูปช่องว่าง (Spaces Loop) ทิ้งไป จะได้สามเหลี่ยมมุมฉาก
⚠️ จุดที่ต้องระวัง & กับดักข้อสอบ (Common Mistakes & Traps)
จุดที่ห้ามทำผิด: 1. ใช้เครื่องหมาย ^ แทนยกกำลัง (เช่น 2 ^ col) ซึ่งผิด เพราะใน Java ต้องใช้ (int)Math.pow(2, col)
2. ลืมหรือคำนวณจำนวนช่องว่างผิด ทำให้ตัวเลขเอียงกลายเป็นสามเหลี่ยมมุมฉาก ไม่ใช่พีระมิดหน้าจั่วกึ่งกลาง

เรียนรู้โครงสร้างการประกาศฟังก์ชันที่ส่งค่ากลับ (Value-returning method), การส่งผ่าน Parameters, และเทคนิคการเรียก Method ซ้อนกันเพื่อหาค่ามากสุดในหลายตัวแปร

// SE101 - Lab 10A: Exercise 1 & 2 (TestMax.java) public class TestMax { public static void main(String[] args) { int i = 5; int j = 2; int x = 9; int y = 7; // Exercise 1: Max between two numbers int k = max(i, j); System.out.println("Max = " + k); // Exercise 2: Max among four numbers using nested max() calls int max4 = max(max(i, j), max(x, y)); System.out.println("The maximum between " + i + ", " + j + ", " + x + " and " + y + " is " + max4); } public static int max(int num1, int num2) { int result; if (num1 > num2) { result = num1; } else { result = num2; } return result; } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. สร้าง Method public static int max(int num1, int num2)
  2. ภายใน Method: ใช้เงื่อนไข if (num1 > num2) return num1; else return num2;

    int largest = max(max(i, j), max(k, l));
    - Java จะคำนวณ max(i, j) ก่อน
    - ตามด้วยคำนวณ max(k, l)
    - แล้วนำผลลัพธ์ของทั้งสองคู่มาหา max() อีกครั้งในรอบสุดท้าย
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)

ฝึกการแยกฟังก์ชันคำนวณผลรวมตัวเลขจากขอบเขตเริ่มต้นถึงสิ้นสุด เพื่อให้โค้ดส่วนคำนวณสามารถนำกลับมาใช้ซ้ำ (Reusable) ได้หลายครั้ง

// SE101 - Lab 10A: Exercise 3 (SumRange.java) public class SumRange { public static void main(String[] args) { System.out.println("Sum from 1 to 10 is " + sum(1, 10)); System.out.println("Sum from 20 to 30 is " + sum(20, 30)); System.out.println("Sum from 35 to 45 is " + sum(35, 45)); } public static int sum(int i1, int i2) { int total = 0; for (int i = i1; i <= i2; i++) { total += i; } return total; } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)

  5. ใน main(): เรียกใช้งานฟังก์ชันซ้ำ 3 ครั้งในช่วงต่างๆ ได้แก่ 1 ถึง 10, 20 ถึง 37, และ 35 ถึง 49

Math Library & Multi-parameter Method Lab10A_Methods1/Distance.java
🎯 จุดประสงค์และเป้าหมายของโปรแกรม
สร้างฟังก์ชันรับพิกัด 4 จุด $(x_1, y_1)$ และ $(x_2, y_2)$ แล้วคำนวณระยะทางแบบยูคลิดโดยใช้ฟังก์ชันจากคลาส Math
ซอร์สโค้ดฉบับสมบูรณ์ (Distance.java):
// SE101 - Lab 10A: Exercise 5 (Distance.java) import java.util.Scanner; public class Distance { public static void main(String[] args) { Scanner scanner = new Scanner(System.in); System.out.print("Enter point 1 (x y): "); double x1 = scanner.nextDouble(); double y1 = scanner.nextDouble(); System.out.print("Enter point 2 (x y): "); double x2 = scanner.nextDouble(); double y2 = scanner.nextDouble(); double dist = distance(x1, y1, x2, y2); System.out.printf("Distance = %.2f%n", dist); scanner.close(); } public static double distance(double x1, double y1, double x2, double y2) { return Math.sqrt(Math.pow(x2 - x1, 2) + Math.pow(y2 - y1, 2)); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. ประกาศ Method: public static double distance(double x1, double y1, double x2, double y2)
  2. คำนวณผลต่างพิกัด: $\Delta x = x_2 - x_1$ และ $\Delta y = y_2 - y_1$
  3. ใช้สูตรระยะทาง: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
  4. เขียนคำนวณใน Java: return Math.sqrt(Math.pow(x2 - x1, 2) + Math.pow(y2 - y1, 2));
  5. ใน main(): รับพิกัดทั้ง 4 ค่าจาก Scanner แล้วส่งเข้า Method แสดงผลด้วยทศนิยม 2 ตำแหน่ง
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
ตัวอย่างการคำนวณพิกัด (x1=1.5, y1=-3.4) ถึง (x2=4.0, y2=5.0): Δx = 4.0 - 1.5 = 2.5 -> (2.5)^2 = 6.25 Δy = 5.0 - (-3.4) = 8.4 -> (8.4)^2 = 70.56 ผลรวม = 6.25 + 70.56 = 76.81 ระยะทาง = sqrt(76.81) = 8.764... หน้าจอ Output: The distance between the two points is 8.76

พิสูจน์และทำความเข้าใจกลไก Pass-by-Value ของตัวแปรชนิด Primitive (int, double, boolean) ว่าการแก้ไขค่าพารามิเตอร์ภายใน Method จะไม่ส่งผลกระทบต่อตัวแปรต้นทางในฟังก์ชันผู้เรียก
ซอร์สโค้ดฉบับสมบูรณ์ (PassByValue.java):
public class PassByValue { public static void main(String[] args) { int num = 10; System.out.println("Before: num = " + num); increment(num); System.out.println("After: num = " + num); } public static void increment(int n) { n = n + 1; System.out.println("Inside: n = " + n); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. ใน main() ประกาศตัวแปร int x = 1;
  2. แสดงค่าก่อนเรียก Method: "Before the call, x is 1"
  3. เรียกใช้ Method: increment(x); โดย Java จะทำการ Copy ค่า 1 ไปใส่ไว้ในพารามิเตอร์ n ของ Method
  4. ใน Method increment(int n): สั่ง n++; ทำให้ตัวแปร copy (n) มีค่ากลายเป็น 2
  5. กลับมาที่ main(): พิมพ์ค่าตัวแปร x อีกครั้ง ค่าของ x ใน main ยังคงเป็น 1 เท่าเดิมไม่เปลี่ยนแปลง
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
ลำดับและสถานะตัวแปรในหน่วยความจำ: 1. main() เริ่มทำงาน: สร้างกล่องตัวแปร x = 1 ใน main stack frame 2. เรียก increment(x): สร้าง stack frame ใหม่สำหรับ increment มีกล่อง n = 1 (copy จาก x) 3. ภายใน increment: n++ -> กล่อง n เปลี่ยนเป็น 2 4. increment ทำงานจบ: stack frame ของ increment ถูกทำลายทิ้งไป 5. main() ทำงานต่อ: กล่องตัวแปร x ยังคงมีค่าเป็น 1 เสมอ! หน้าจอ Output: Before the call, x is 1 n inside the method is 2 After the call, x is 1
🔄 แบบต่างๆ และรูปแบบที่อาจเจอในข้อสอบ (Variations & Exam Tweaks)
  • ต้องการให้ค่าใน main เปลี่ยน: ต้องให้ Method คืนค่ากลับมา แล้วรับค่าทับ:
    x = increment(x); โดย Method นิยาม public static int increment(int n) { return n + 1; }
  • เปรียบเทียบกับ Array (Pass-by-Reference): หากส่ง Array เข้าไป การแก้ค่าสมาชิกใน Array ภายใน Method จะทำให้ Array ต้นทางเปลี่ยนไปด้วยจริง
⚠️ จุดที่ต้องระวัง & กับดักข้อสอบ (Common Mistakes & Traps)
เข้าใจผิดว่าเมื่อตั้งชื่อพารามิเตอร์ให้ตรงกับชื่อตัวแปรใน main (เช่น ใช้ int x เหมือนกันทั้งใน main และใน method) แล้วค่าจะเปลี่ยนตามกัน ใน Java เป็นคนละตัวแปรและอยู่คนละขอบเขต (Scope) เสมอ

import java.util.Scanner; public class GCDModular { public static void main(String[] args) { Scanner input = new Scanner(System.in); System.out.print("Enter n1: "); int n1 = input.nextInt(); System.out.print("Enter n2: "); int n2 = input.nextInt(); int result1 = gcd(n1, n2); System.out.println("GCD(" + n1 + ", " + n2 + ") = " + result1); int newN1 = n1 * 2; int newN2 = n2 * 3; int result2 = gcd(newN1, newN2); System.out.println("GCD(" + newN1 + ", " + newN2 + ") = " + result2); } public static int gcd(int n1, int n2) { int gcd = 1; int min = Math.min(n1, n2); for (int k = 2; k <= min; k++) { if (n1 % k == 0 && n2 % k == 0) { gcd = k; } } return gcd; } }

    public static int gcd(int n1, int n2)
  2. ภายใน Method: ทำงานด้วย Brute-force หรือ Euclidean Algorithm แล้วส่งค่า return gcd;
  3. ในฟังก์ชัน main(): รับหน้าที่เฉพาะการติดต่อกับผู้ใช้ (User Interface) รับตัวเลข n1, n2 จาก Scanner
  4. เรียกใช้ฟังก์ชัน int result = gcd(n1, n2); แล้วนำผลลัพธ์มาพิมพ์แสดงอย่างสวยงาม

เข้าใจนิยามของจำนวนสมบูรณ์ (Perfect Number คือ จำนวนเต็มบวกที่มีค่าเท่ากับผลรวมของตัวหารแท้ทั้งหมดที่ไม่รวมตัวมันเอง เช่น 6 = 1 + 2 + 3) และการค้นหาในช่วงตัวเลขขนาดใหญ่
ซอร์สโค้ดฉบับสมบูรณ์ (Perfectnumber.java):
public class Perfectnumber { public static void main(String[] args) { // วนลูปเพื่อหา Perfect Number ที่มีค่าน้อยกว่า 10000 for (int i = 1; i < 10000; i++) { if (isPerfect(i)) { System.out.println(i + " is a perfect number"); } } } public static boolean isPerfect(int number) { int sum = 0; // ลูปหาตัวหารทั้งหมด (ยกเว้นตัวมันเอง) for (int k = 1; k < number; k++) { // ถ้าหารลงตัว ให้นำไปบวกใน sum if (number % k == 0) { sum += k; } } // ถ้าผลรวมเท่ากับตัวมันเองพอดี จะถือว่าเป็น Perfect Number (return true) return sum == number; } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. สร้าง Method ตรวจสอบ: public static boolean isPerfect(int n)
  2. ภายใน Method: สร้างตัวแปรสะสมผลรวมตัวหาร int sum = 0;
  3. วนลูปหาตัวหารแท้: for (int d = 1; d < n; d++) (ย้ำว่า d < n ไม่รวมตัวมันเอง)
  4. ถ้า d หาร n ลงตัว: if (n % d == 0) sum += d;
  5. ส่งผลลัพธ์: return (sum == n); (จริงเมื่อผลรวมตัวหารเท่ากับ n พอดี)
  6. ใน main(): วนลูปทดสอบตั้งแต่ 1 ถึง 10,000 หาก isPerfect(i) เป็นจริงให้แสดงผล
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
การตรวจสอบตัวเลขตัวอย่าง: - เลข 6: ตัวหารแท้คือ 1, 2, 3 -> sum = 1 + 2 + 3 = 6 == 6 -> True (เป็น Perfect Number!) - เลข 28: ตัวหารแท้คือ 1, 2, 4, 7, 14 -> sum = 28 == 28 -> True (เป็น Perfect Number!) - เลข 10: ตัวหารแท้คือ 1, 2, 5 -> sum = 8 != 10 -> False ผลการรันหาตั้งแต่ 1 ถึง 10,000: The perfect numbers between 1 and 10000 are: 6 28 496 8128
🔄 แบบต่างๆ และรูปแบบที่อาจเจอในข้อสอบ (Variations & Exam Tweaks)
  • เพิ่มประสิทธิภาพ: วนลูปหาตัวหารแค่ d <= n / 2 เพราะตัวหารแท้ที่ใหญ่ที่สุดไม่มีทางเกินครึ่งหนึ่งของตัวเลข
  • จำนวนบกพร่อง (Deficient) และจำนวนเกิน (Abundant): ถ้า sum < n เรียก Deficient, ถ้า sum > n เรียก Abundant
  • พิมพ์ตัวหารแท้แจกแจงออกมา: แสดง 6 = 1 + 2 + 3
⚠️ จุดที่ต้องระวัง & กับดักข้อสอบ (Common Mistakes & Traps)
วนลูปโดยใช้ d <= n (มีเครื่องหมายเท่ากับ) ทำให้ตัวเลขตัวมันเองถูกบวกเข้าไปใน sum ด้วย ผลรวมจะกลายเป็น $2n$ เสมอ และไม่มีทางเท่ากับ $n$ ส่งผลให้หาจำนวนสมบูรณ์ไม่เจอเลยแม้แต่ตัวเดียว

Searching Algorithms Lab11A_1DArrays/LinearSearch.java

สร้างอัลกอริทึมค้นหาค่าเป้าหมาย (Target) ใน Array แบบ Linear Search โดยเปรียบเทียบทีละตัวตั้งแต่ต้นจนจบ และหยุดค้นหาทันทีเมื่อพบ (Early Break)
ซอร์สโค้ดฉบับสมบูรณ์ (LinearSearch.java):
import java.util.Scanner; public class LinearSearch { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Enter array size (3-10): "); int n = sc.nextInt(); int[] arr = new int[n]; for (int i = 0; i < n; i++) { System.out.print("Enter element [" + i + "]: "); arr[i] = sc.nextInt(); } System.out.print("Enter target to search: "); int target = sc.nextInt(); int foundAt = -1; // -1 หมายถึงยังไม่พบ for (int i = 0; i < arr.length; i++) { if (arr[i] == target) { foundAt = i; break; // หยุดลูปทันทีที่เจอ } } if (foundAt != -1) { System.out.println("Found " + target + " at index " + foundAt); } else { System.out.println(target + " not found in the array."); } sc.close(); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. มี Array ข้อมูล และรับค่าเป้าหมายที่ต้องการค้นหา int target = sc.nextInt();
  2. สร้างตัวแปรเก็บตำแหน่งผลลัพธ์: int foundIndex = -1; (กำหนดค่าเริ่มต้นเป็น -1 เพื่อเป็นตัวแทนของ 'ยังไม่พบ')
  3. วนลูปตรวจสอบสมาชิกทีละตัว: for (int i = 0; i < arr.length; i++)
  4. หากพบว่า arr[i] == target:
    - บันทึกตำแหน่ง: foundIndex = i;
    - สั่ง break; ทันทีเพื่อไม่ให้เสียเวลาค้นหาต่อในช่องที่เหลือ
  5. หลังจบลูป: ตรวจสอบ if (foundIndex != -1) พบข้อมูลที่ Index นั้น ถ้าเท่ากับ -1 แสดงว่าไม่พบ
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)

import java.util.Scanner; public class CountFilter { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Enter array size (3-10): "); int n = sc.nextInt(); int[] arr = new int[n]; int sum = 0; for (int i = 0; i < n; i++) { System.out.print("Enter element [" + i + "]: "); arr[i] = sc.nextInt(); sum += arr[i]; } // (a) นับและแสดงเลขคู่ System.out.print("Even numbers: "); int evenCount = 0; for (int i = 0; i < arr.length; i++) { if (arr[i] % 2 == 0) { System.out.print(arr[i] + " "); evenCount++; } } System.out.println(" (count = " + evenCount + ")"); // คำนวณค่าเฉลี่ย double avg = (double) sum / arr.length; System.out.printf("Average = %.2f\n", avg); // (b) นับและแสดงตัวเลขที่มากกว่าค่าเฉลี่ย System.out.print("Above average: "); int aboveAvgCount = 0; for (int i = 0; i < arr.length; i++) { if (arr[i] > avg) { System.out.print(arr[i] + " "); aboveAvgCount++; } } System.out.println(" (count = " + aboveAvgCount + ")"); sc.close(); } }

In-Place Array Manipulation Lab11A_1DArrays/ReverseArray.java
🎯 จุดประสงค์และเป้าหมายของโปรแกรม
สร้างอัลกอริทึมกลับลำดับข้อมูลใน Array จากหน้าไปหลัง โดยใช้หน่วยความจำเดิมที่มีอยู่โดยไม่สร้าง Array ใหม่ (In-Place Algorithm) ด้วยเทคนิค Two Pointers
ซอร์สโค้ดฉบับสมบูรณ์ (ReverseArray.java):
import java.util.Scanner; public class ReverseArray { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Enter array size (3-10): "); int n = sc.nextInt(); int[] arr = new int[n]; for (int i = 0; i < n; i++) { System.out.print("Enter element [" + i + "]: "); arr[i] = sc.nextInt(); } // พิมพ์ค่าก่อนกลับด้าน System.out.print("Before: "); for (int i = 0; i < arr.length; i++) { System.out.print(arr[i] + " "); } System.out.println(); // อัลกอริทึม In-place Reversal (สลับซ้าย-ขวา) int left = 0; int right = arr.length - 1; while (left < right) { int temp = arr[left]; arr[left] = arr[right]; arr[right] = temp; left++; right--; } // พิมพ์ค่าหลังกลับด้าน System.out.print("After: "); for (int i = 0; i < arr.length; i++) { System.out.print(arr[i] + " "); } System.out.println(); sc.close(); } }
⚙️ หลักการทำงานอย่างละเอียด (Step-by-Step Logic)
  1. กำหนดตัวชี้สองฝั่ง:
    - int left = 0; (ชี้ที่หัว Array)
    - int right = arr.length - 1; (ชี้ที่ท้าย Array)
  2. วนลูปตราบเท่าที่ตัวชี้ทั้งสองยังไม่เดินมาชนหรือสวนทางกัน: while (left < right)
  3. การสลับค่า (Swap) ด้วยตัวแปรพักค่า (temp):
    1. int temp = arr[left]; (เก็บค่าซ้ายไว้ชั่วคราว)
    2. arr[left] = arr[right]; (เอาค่าขวามาใส่ซ้าย)
    3. arr[right] = temp; (เอาค่าเดิมของซ้ายมาใส่ขวา)
  4. ขยับตัวชี้: left++; (ขยับไปทางขวา) และ right--; (ขยับไปทางซ้าย)
  5. เมื่อลูปจบ ข้อมูลใน Array จะถูกกลับด้านอย่างสมบูรณ์
📊 ตัวอย่างการทำงานและการ Trace ตัวแปร (Trace Table & Walkthrough)
จำลองการสลับ Array [1, 2, 3, 4, 5]: เริ่มต้น: left = 0 (ค่า 1), right = 4 (ค่า 5) รอบที่ 1: สลับ arr[0] กับ arr[4] -> [5, 2, 3, 4, 1] left เพิ่มเป็น 1, right ลดเหลือ 3 รอบที่ 2: สลับ arr[1] กับ arr[3] -> [5, 4, 3, 2, 1] left เพิ่มเป็น 2, right ลดเหลือ 2 รอบที่ 3: left = 2, right = 2 -> เงื่อนไข left < right เป็นเท็จ -> จบลูป! ผลลัพธ์: Array กลับด้านเป็น [5, 4, 3, 2, 1] สำเร็จโดยใช้หน่วยความจำคงที่ O(1)
🔄 แบบต่างๆ และรูปแบบที่อาจเจอในข้อสอบ (Variations & Exam Tweaks)
  • เขียนโดยใช้ For Loop แบบครึ่งทาง:

  • สร้าง Array ใหม่มารับค่า (ไม่ In-place): สร้าง int[] rev = new int[n]; แล้วคัดลอกจากหลังมาหน้า
  • สลับเฉพาะครึ่งแรกหรือครึ่งหลัง
⚠️ จุดที่ต้องระวัง & กับดักข้อสอบ (Common Mistakes & Traps)
ข้อผิดพลาดร้ายแรงที่สุด: เขียนลูป for (int i = 0; i < arr.length; i++) โดยไม่มีเงื่อนไขหยุดที่กึ่งกลาง ลูปจะทำการสลับตัวเลขไปจนถึงตัวสุดท้าย ส่งผลให้ตัวเลขถูกสลับไปแล้วถูกสลับกลับคืนมาเป็น Array หน้าตาเหมือนเดิมก่อนสลับ!

🔥 อันดับที่ 1: Integer Division (การหารจำนวนเต็มตัดเศษ)

✅ เขียนแบบนี้ (ถูกต้อง / เต็ม 100%):
double avg = (double) sum / n; // ได้ 6.25 ถูกต้อง
